# 센터필드 새로운 시선

스타벅스 코리아가 있는 센터필드 이스트(서울 강남구 테헤란로 231)를 웹 3D로 재구성한 비공식 건축 시각화입니다.

- 두 타워 외관, 건물 펼치기(유리·구조 프레임·층판·승강기·계단·설비)
- 20–22F 스타벅스 코리아 층 클로즈업
- B1 스타벅스 센터필드R점 클로즈업과 B1–B7 지하 단면, 최신 출시 메뉴 패널
- 낮/밤 모드(기본은 밤), 36초 자동 둘러보기

## 안내

실측·설계 도면 기반이 아니며, 내부 구조와 매장·지하 배치는 전시용으로 재구성했습니다.
스타벅스 및 SCK컴퍼니의 공식 프로젝트가 아닙니다. 상표 로고 대신 직접 그린 도트 별 기호를 사용했습니다.
